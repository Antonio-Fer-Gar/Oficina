    Jefe humano · Usage de omp

    Skills globales

    Las skills activadas estarán disponibles en cualquier proyecto y omp recibirá la instrucción de leerlas al empezar cada tarea. El agente decide cómo aplicarlas. Inicia una sesión nueva para aplicar los cambios.

    Adjunta solo skills de confianza: pueden contener instrucciones y scripts. La oficina no ejecuta esos scripts.

    Catálogo de skills Nter

    Carga el catálogo con un Chrome dedicado. La primera vez tendrás que iniciar sesión en la ventana que se abrirá.

      El selector de carpetas de Windows solo muestra carpetas, no archivos. Elige la carpeta de la skill o la carpeta descargada que la contiene; se copiarán sus recursos. Para elegir el archivo visible, usa «Adjuntar archivo SKILL.md» (solo se copiará ese archivo).
